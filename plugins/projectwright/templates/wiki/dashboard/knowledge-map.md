# Knowledge map

Navigation hub of the wiki. To get oriented in a session: first [[project-status]], then [[operating-assumptions]] if you are about to write code, then the note of the topic. Terms are in the [[glossary]]; the writing rules are in the constitution (`wiki/README.md`).

This note keeps **only the reading paths**, written by hand. The lists of notes, decisions and questions are computed views: they never go out of date.

## Reading paths

| If you… | Read, in order |
|---|---|
| **Are new to the project** | <context> → <actors> → <scope> → [[project-status]] |
| **Are about to write code on a component** | [[operating-assumptions]] → <bridge note of the standards> → <entry note of the component> → <domain notes of the area> |
| **Need to talk with another team** | <contracts between components> → <inter-stream questions> |
| **Need to ingest or integrate documentation** | constitution → `wiki-sources/README.md` → open questions |
